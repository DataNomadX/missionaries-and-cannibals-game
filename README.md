# 🛶 Missionaries and Cannibals Game

A Python command-line implementation of the classic **Missionaries and Cannibals** puzzle.

## 📌 About
---

This project simulates the famous river-crossing problem where 3 missionaries and 3 cannibals must cross a river safely.

### Rules:
- Boat can carry at most 2 people
- If cannibals outnumber missionaries on either side, missionaries get eaten
- The goal is to safely move everyone to the left side

---

The game starts with 3 missionaries and 3 cannibals on one side of the river. The player must move them across using a boat that can carry at most 2 people at a time. The main rule is that cannibals should never outnumber missionaries on either side, otherwise the player loses.

The game takes user input for the number of missionaries and cannibals to move in each step and updates the state accordingly. It continues until the player either wins or loses.

This project was built step-by-step, focusing on basic Python concepts like loops, conditionals, and input handling.
